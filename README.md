# Hi, I'm Luca 👋

Founder of **[TZEKOS[dot]EU](https://tzekos.eu)** — a small studio in Thessaloniki, Greece, building data and API products.

## What I'm building

- **[Job Opportunities API](https://jobopportunitiesapi.org)** — a ledger of more than 2 million live job listings taken straight from employer ATS platforms, company career pages and public employment agencies. Every field is labelled *published* or *inferred*, and every row says when it was last verified. Free tier, REST API, OpenAPI spec.
  - REST docs and pricing: [jobopportunitiesapi.org](https://jobopportunitiesapi.org)
  - Pay-per-call on [API.market](https://api.market/store/tzekos/jobopportunitiesapi)
  - Pay-per-result on Apify: [`job-opportunities-api`](https://apify.com/job_opportunities_api/job-opportunities-api) — source in [JOA-Apify](https://github.com/lucagiftzek/JOA-Apify)
- **[Erioun](https://erioun.com)** and **[Kaeros](https://kaeros.app)** — career and job-search products built on the same data pipeline.
